# JSONSerializationDemo2  
**Fetch Simple API and display in Table View**

---

### Description ->

The **JSONSerializationDemo2** iOS App is a simple project built using Swift and UIKit to help understand how to fetch and display data from an API using `URLSession` and `JSONSerialization`. It uses a single view controller that sends a GET request to a photo API and displays the response data in a table view. Each cell in the table view shows the photo's ID, title, URL, and thumbnail URL using a custom table view cell.

This project is useful for learning how to perform API requests, manually parse JSON, and display data in a structured format using `UITableView`.

---

### Features ->

- Sends a GET request to a public API: [https://jsonplaceholder.typicode.com/photos](https://jsonplaceholder.typicode.com/photos)  
- Uses `URLSession` for asynchronous networking  
- Parses raw JSON into a custom model using `JSONSerialization`  
- Displays the data in a scrollable `UITableView`  
- Implements a custom `UITableViewCell` with labels for photo ID, title, URL, and thumbnail URL
